OVERVIEW

安全加固版 ETS2LA

这是基于 ETS2LA 3.4.37 的派生项目，保留原有插件 API，同时优先修复插件供应链、控制融合、配置隔离和可复现构建问题。

✓

安全插件链路

HTTPS、SHA-256、ZIP 路径检查、事务安装与失败回滚。

◎

失效安全输出

有限浮点值、正权重、线程安全快照和可取消控制线程。

⌘

可复现工程

固定 SDK、集中依赖、NuGet lock files 和跨平台构建脚本。

DEVELOPMENT ENVIRONMENT

安装构建环境

从 GitHub 下载源码后，先准备 .NET 10 SDK、Git 和 NuGet 网络访问。项目不需要 Node.js 或前端构建工具，GitHub Pages 文档站本身是静态文件。

Windows

  1. 安装 .NET 10 SDK ↗，版本选择 10.0.400 或更高的 10.0.x。
  2. 安装 Git，并确认 PowerShell 能执行 git --version。
  3. 打开项目目录，运行 dotnet --version，确认输出以 10.0. 开头。
PowerShell
dotnet --version
git --version

Linux

按发行版安装 .NET 10 SDK，并准备图形、SDL3/输入设备相关运行库；构建入口使用 Bash。

Shell
dotnet --version
git --version
chmod +x build.sh

还原依赖

首次构建需要访问 NuGet。项目包含包锁文件，Windows 发布会为 win-x64 更新锁定目标，Linux 发布会为 linux-x64 更新锁定目标。还原失败时先检查网络、代理和 SDK 版本。

不需要用户不需要下载 ETS2/ATS 游戏资源才能完成源码构建；但真实驾驶接入仍需要合法安装游戏、SCS SDK 和驾驶插件。

ARCHITECTURE

架构

宿主按 UI、Backend、Game、State、Networking 和 Overlay 分层，插件通过公共契约和事件总线接入。

游戏遥测→State→插件算法→ControlMixer→共享内存输出
  • Game：读取 SCS SDK 共享内存、解析地图并向游戏写入控制。
  • Backend：隔离加载第三方插件，管理生命周期和依赖。
  • Networking：获取插件目录、校验包并执行事务安装。
  • UI/Overlay：Avalonia 桌面窗口与 ImGui/OpenGL 覆盖层。
SECURITY MODEL

安全模型

插件 DLL 在宿主进程内运行，因此完整性验证是安装边界，而不是权限沙箱。所有在线插件都必须经过明确校验。

边界策略
下载仅允许 HTTPS，并拒绝带凭据的 URL。
完整性提供 SHA-256 时严格校验；旧目录无摘要时只允许 HTTPS 并记录警告。
压缩包拒绝穿越、重解析点、超大归档和过多条目。
安装staging → 校验 → 原子切换；失败恢复旧版本。
控制slew-rate 限幅；遥测超过 2 秒未更新时立即复位为中性，恢复后平滑接管；超过“最高速度”（m/s 存储、UI 按 km/h/mph 显示）时禁止正油门并渐进制动。
凭据Windows 使用 DPAPI，普通 JSON 不保存 JWT。

BOUNDARIES

限制与边界

当前仓库已验证源码还原、编译、单元测试、Windows x64 发布和 smoke test，但尚未在本环境连接真实 ETS2/ATS 进程。

不要误用不要把来源不明的 DLL、游戏资源、用户配置或 JWT 放入仓库；不要在没有真实游戏和测试插件时验证控制输出。
